Soalan lazim

Adakah ini harga kedai emas?

Tidak. Ini harga rujukan spot. Harga kedai biasanya termasuk premium, upah dan spread.

Adakah HargaEmas.my sumber rasmi?

Tidak. HargaEmas.my (HRGMS) ialah portal dan penyedia API yang mengagregat sumber pasaran. Untuk harga rasmi jenama tertentu, rujuk laman penyedia itu.

Di mana API harga emas?

Endpoint awam: https://api.hargaemas.my/prices dan https://hargaemas.my/api/gold-prices.json.
